# web-ui-react

React-komponenter ovanpå [React Aria](https://react-spectrum.adobe.com/react-aria/) som sätter
[web-ui](https://github.com/Kodhast/web-ui):s `kh-*`-klasser. web-ui ger utseendet (som följer android-ui),
React Aria tryck, fokus och tangentbord. Biblioteket har inget eget CSS. Varför: [beslut 0001](docs/beslut/0001-react-aria-kh-js-och-bygget.md); dialog och ark: [beslut 0002](docs/beslut/0002-dialog-och-ark-pa-inbyggd-dialog.md).

## Använda i en app

```json
"dependencies": {
	"@kodhast/web-ui": "github:Kodhast/web-ui#v2.0.0",
	"@kodhast/web-ui-react": "github:Kodhast/web-ui-react#v0.8.0",
	"react": "^19.3.1",
	"react-dom": "^19.3.1"
}
```

Appen importerar web-ui:s tal och klasser och sitt eget tema (färger och typsnitt), som förut:

```ts
import '@kodhast/web-ui/tokens.css';
import '@kodhast/web-ui/kh.css';
import './tema.css';
```

`kh.js` behövs inte för komponenterna här.

```tsx
import { Button } from '@kodhast/web-ui-react';

<Button variant="primary" onPress={spara} isPending={sparar}>
	Spara
</Button>;
```

## Komponenterna

| Komponent             | web-ui                                             | android-ui                   | Anmärkning                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| --------------------- | -------------------------------------------------- | ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Button`              | `kh-btn`                                           | `AppButton`                  | `variant`: `tonal` (standard), `primary` (vyns primära handling, högst en per vy), `outlined`, `text`, `destructive`, `destructiveText`. `compact`, `block`, `icon` (en `<svg>` före texten), `isDisabled`, `isPending` (prickarna i ikonens ställe, `aria-busy`, trycks inte men behåller färgen och fokus; `isDisabled` vinner), `ref`. Övriga props som React Aria:s `Button` (`onPress`, `type`, `aria-label` …). `buttonClass()` ger klasserna för en länk som ska se ut som en knapp.                                                                                                                                           |
| `Dots`                | `<kh-dots>`                                        | `BrandDots`                  | `bouncing` hoppar. Ritar sina två `<i>` själv, utan `kh.js`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `Card`                | `kh-card`                                          | `AppCard`                    | `tone` (appens tonklass, t.ex. `ton-gron`, med `kh-card--tone`). Statisk, länk med `href` eller knapp med `onPress` (`aria-label` när innehållet saknar namn).                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `Row`                 | `kh-row`                                           | `ItemRow`                    | `title`, `subtitle`, `leading`, `trailing`, `navigates` (chevronen), `tinted`, `done`, `inactive`, `accentClass`. Statisk, länk eller knapp som `Card`. **Accenten:** web-ui sätter `--kh-accent` med `style`, men här sätts ingen `style`. Appen skriver i stället en klass, t.ex. `.accent-fel { --kh-accent: var(--kh-error); }`, och skickar dess namn.                                                                                                                                                                                                                                                                           |
| `Chevron`             | `kh-chevron`                                       | pilen i `ItemRow(navigates)` | För egna rader; `Row` och `Notice` ritar den själva.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `Pill`, `Pills`       | `kh-pill`, `kh-pills`                              | `InfoPill`                   | `tone`, `square`, knapp med `onPress`. Ikonen som `<svg>` före eller efter texten.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `Notice`              | `kh-notice`                                        | `NoticeBanner`               | `title`, `detail`, `icon`, `tone`, `action` (en knapp under texten; inte i en länk), länk eller knapp med chevronen.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `EmptyState`          | `kh-empty`                                         | `EmptyState`                 | `title`, `text`, `icon`, `actions`, `note`, `variant` (`error`, `compact`, `fullscreen`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `TextField`           | `kh-field-group`, `kh-field`                       | `AppTextField`               | `label`, `suffix`, `description` (hjälptext, kopplas med `aria-describedby`), `errorMessage` (`aria-invalid` och `kh-field__support--error`; ersätter hjälptexten), `multiline` (`<textarea>`), `isDisabled`, `action` (`{ icon, label, onPress }`: en ikonknapp sist i fältet). `value`/`defaultValue`/`onChange` och övriga props som React Aria:s `TextField`. Omslaget är en `<label>` som i web-ui, så ett tryck var som helst i fältet fokuserar det; namnet kommer ur `aria-labelledby`.                                                                                                                                       |
| `Switch`, `SwitchRow` | `kh-switch`, `kh-switch-row`                       | `SwitchControl`, `SwitchRow` | `isSelected`/`defaultSelected`/`onChange`, `isDisabled`. `Switch` kräver `aria-label`. `SwitchRow`: `title`, `subtitle`, `inactive` (texten tonas ned, växeln inte). Hela raden är en `<label>`. React Aria:s `Switch` kan inte användas: dess `<input>` är dold med `style`, och `kh-switch` är själva `<input>`:en (`:checked`), så `useSwitch` används direkt.                                                                                                                                                                                                                                                                     |
| `SegmentedChoice`     | `kh-segmented`                                     | `AppSegmentedChoice`         | `options` (`value`, `label`, `isDisabled`), `value`/`defaultValue`/`onChange`, `isDisabled`, `aria-label`. Byggt på `ToggleButtonGroup` (ett val, alltid ett valt): `role="radiogroup"` och `role="radio"` med `aria-checked`, som `kh.css` läser. Pilarna flyttar valet med fokus, som i en inbyggd radiogrupp (beslut 0001, följder).                                                                                                                                                                                                                                                                                               |
| `FilterChips`         | `kh-chips`, `kh-chip`                              | `ChipRow`, `AppFilterChip`   | `options` (`value`, `label`, `icon`, `count`, `emphasized`, `pending`, `isDisabled`), `selected`/`defaultSelected`/`onChange` (listor av `value`), `aria-label`. `ToggleButtonGroup` med flera val: `aria-pressed`.                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `Stepper`             | `kh-stepper`, `kh-stepper-field`                   | `QuantityStepper`            | `label` (namnger knapparna: "Minska doser per dag", "Öka doser per dag"), `value`/`defaultValue`/`onChange`, `min`, `max`, `step`, `formatOptions` (värdet visas som `Intl.NumberFormat` säger), `isDisabled`, `showLabel` (etiketten bredvid). Knappen vid gränsen är avstängd. Ritar `<kh-stepper>` själv, utan `kh.js`; `<output>` visar värdet och React Aria:s `NumberField`-`<input>` är dolt (`hidden`). Knapparna nås med Tab (stegarens knappar i `kh.js` gör det också). `--kh-stepper-button: 48px` sätts av appen i en klass runt stegaren.                                                                               |
| `IconButton`          | `kh-icon-btn`                                      | `AppIconButton`              | `aria-label` (krävs av typen), `children` (ikonen, en `<svg>`), `tonal` (plattan; vanlig som standard), `tone` (appens tonklass), `onPress`, `isDisabled`, `href` (en länk), `ref`. `TextField`:s `action` och `TopBar`:s tillbakapil är `IconButton`.                                                                                                                                                                                                                                                                                                                                                                                |
| `Header`              | `<kh-header>`                                      | `AppHeader`                  | `title` (`<h1>`), `icon` (appens ikon, får `kh-header__icon`), `name`, `subtitle`, `trailing` (t.ex. kontots avatar), `dots`, `bouncing`. Krymper och höjs vid rullning med web-ui:s CSS för `kh-header` utan `kh.js` (web-ui 2.1.0, närmaste rullande förälder); här läses ingen rullning.                                                                                                                                                                                                                                                                                                                                           |
| `PeriodPicker`        | `kh-period`                                        | – (bara webben)              | `label` (texten, avkortas på en rad), `onPrevious`, `onNext`, `previousLabel` och `nextLabel` (pilarnas namn, standard "Föregående" och "Nästa"), `isPreviousDisabled`, `isNextDisabled`, `onLabelPress` (etiketten är en knapp; vad den öppnar avgör appen), `aria-label` (gruppens). Appen äger datumet; inget eget tillstånd.                                                                                                                                                                                                                                                                                                      |
| `ReorderList`         | `kh-reorder`                                       | – (bara webben)              | `items` (`id`, `title`, `subtitle`, `textValue`), `onReorder(ids)` (den nya ordningen; appen äger den), `handleLabel` (standard "Flytta <textValue>"), `aria-label`. React Aria:s `GridList` med `useDragAndDrop`: raden dras med mus eller finger, handtaget med tangentbordet. React Aria sätter två `style` som inte ändrar utseendet (cellen `display: contents`, handtaget `pointer-events: none`). `reorder()` räknar fram ordningen.                                                                                                                                                                                           |
| `TopBar`              | `<header class="kh-topbar">`                       | `AppTopBar` (liten)          | `title` (`<h1>`), `onBack` eller `backHref` (tillbakapilen som knapp eller länk, "Tillbaka", tonad), `backLabel`, `plainBack`, `backTone`, `dots`, `bouncing` (prickarna hoppar), `actions` (sist i raden). Oskärpan under raden vid rullning är web-ui:s CSS.                                                                                                                                                                                                                                                                                                                                                                        |
| `Toolbar`             | `<kh-toolbar>` med `__tabs`, `__tab`, `__action`   | `AppFloatingToolbar`         | `tabs` (`id`, `label`, `icon`, `href`, `badge`), `selected` (`id` för sidan som visas: `aria-current="page"`), `action` (`{ label, icon, onPress }`: huvudknappen, t.ex. timerns start och stopp), `fixed` (längst ned på skärmen), `aria-label` (flikarnas `<nav>`). Flikarna är länkar; appens router sköter dem. Märket syns bara på en ovald flik.                                                                                                                                                                                                                                                                                |
| `ConfirmDialog`       | `kh-dialog` med `__title`, `__text`, `__actions`   | `ConfirmDialog`              | `title` (namnger dialogen), `text` (beskriver den), `children` (t.ex. ett `TextField` för ett skäl), `confirmLabel`, `cancelLabel` (standard "Avbryt"), `destructive`, `isOpen`/`onOpenChange`, `onConfirm` (sedan `onOpenChange(false)`), `isConfirmDisabled` (t.ex. tills ett krävt skäl är ifyllt). `role="alertdialog"`. En inbyggd `<dialog>` med `showModal()`, så att slöjan med oskärpa ritas (beslut 0002). Fokus till första fältet eller Avbryt, stannar i dialogen och går tillbaka till knappen som öppnade. Escape, Androids bakåt och ett tryck på slöjan stänger – inte med `destructive`, då stänger bara knapparna. |
| `BottomSheet`         | `kh-sheet` med `__title`, `__subtitle`, `__footer` | `AppBottomSheet`             | `title`, `subtitle`, `footer` (knapparna, fast i botten), `children`, `isOpen`/`onOpenChange`. Samma `<dialog>`, fokus och stängning som `ConfirmDialog`; Escape, bakåt och slöjan stänger alltid.                                                                                                                                                                                                                                                                                                                                                                                                                                    |

## Galleriet

`npm run gallery` visar varje komponent ljust och mörkt med web-ui:s testtema (android-ui:s testpalett,
Roboto, `gallery/fonts/OFL.txt`). `npm run skarmdumpar` tar bilderna i `screenshots/` med samma namn
som web-ui:s, så att de kan jämföras med ögat.
